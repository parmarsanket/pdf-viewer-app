## 🏆 Key Features (Bullet Format for AI/Marketing)

### Core PDF Viewing
- ✅ Open PDFs from any source (file manager, browser, email)
- ✅ Zoom 1x-10x with smooth pinch gesture
- ✅ Fast scroll with page indicator overlay
- ✅ In-PDF text search with highlight
- ✅ Password-protected PDF support
- ✅ Link detection with copy/open options
- ✅ Hide UI mode for distraction-free reading

### Bookmark Management
- ✅ Create bookmarks from any PDF
- ✅ Add priority (High/Medium/Low)
- ✅ Set status (Reading, Reviewed, Important, Pending, Done, On Hold, Rejected)
- ✅ Custom & preset tags (Study, Personal, Office, Presentation, Project)
- ✅ Personal notes per bookmark
- ✅ Edit bookmark metadata anytime
- ✅ Sort by name, file size, or date
- ✅ Filter by priority, status, and tags

### Reading Assistance
- ✅ Auto-scroll for hands-free reading
- ✅ 10-level speed adjustment (1-10)
- ✅ Page Mark to save reading position
- ✅ Auto-Mark mode (auto-save position on exit)
- ✅ Resume reading from last position

### File Management
- ✅ Import single or multiple PDFs
- ✅ Rename PDFs with smart duplicate handling
- ✅ Delete PDFs (single or batch)
- ✅ Share PDFs via any app
- ✅ Multi-select for batch operations
- ✅ Fuzzy search with typo tolerance
- ✅ Thumbnail previews for quick identification
- ✅ Long-press preview overlay

### Sync & Organization
- ✅ Automatic folder sync with PDF_Viewer folder
- ✅ Manual sync refresh
- ✅ Smart change detection (additions/deletions)
- ✅ Progress dialogs for large operations

### Privacy & Security
- ✅ No internet permissions
- ✅ No analytics or tracking
- ✅ Local data storage only
- ✅ SAF-based file access (no MANAGE_EXTERNAL_STORAGE)
- ✅ Google Tink encryption for sensitive data
- ✅ Encrypted password storage per-PDF

### Design & UX
- ✅ Material 3 (Material You) design
- ✅ Dynamic color theming
- ✅ Light and Dark mode
- ✅ Glassmorphism effects
- ✅ Smooth animations (expand, fade, slide)
- ✅ Edge-to-edge display support
- ✅ Floating action toolbars
- ✅ Bottom sheets for details
